
📊 Analyse du chiffre d’affaires et des pertes – Power BI

🎯 **Objectif**
Analyser la performance commerciale et identifier les pertes de chiffre d’affaires liées aux annulations de commandes.

🛠️ **Outils**
Power BI Desktop
DAX
Modélisation de données
📄 Contenu du dashboard

Page 1 : Analyse du chiffre d’affaires vs pertes

<u>Comparaison entre :</u>  
- Commandes en attente  
- Commandes expédiées  
- Commandes livrées  
- Commandes annulées  
Analyse par :
- Produit  
- Catégorie  
- Client  
- Période (mois, trimestre)  

Page 2 : Suivi mensuel et indicateurs

Graphique cumulatif des commandes
Indicateurs :
Taux de manque à gagner
Perte de capacité de production
Répartition des commandes
